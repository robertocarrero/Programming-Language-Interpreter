# Programming Language Interpreter

Java interpreter project built for my Programming Language Concepts course at the University of Florida.

I implemented the main language-processing components, including:

* Lexical analysis and tokenization
* Recursive-descent parsing
* AST evaluation
* Variable scopes and function calls
* Closures and return behavior
* Static type checking and semantic analysis

## Technologies

Java, Gradle, JUnit 5

## Project Structure

```text
src/main/java/plc/project/
├── lexer/
├── parser/
├── evaluator/
└── analyzer/
```

## Notes

The project framework, specifications, and testing infrastructure were provided by the course. My work focused on implementing the lexer, parser, evaluator, and analyzer.
